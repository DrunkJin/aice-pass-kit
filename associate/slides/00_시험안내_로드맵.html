13~14번: 딥러닝 PyTorch로 학습하고 곡선 그리기

Q13
import torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader
torch.manual_seed(42); f32 = torch.float32
X_tr = torch.tensor(X_train.values, dtype=f32)
y_tr = torch.tensor(y_train.values, dtype=f32).view(-1, 1)
X_va = torch.tensor(X_valid.values, dtype=f32)
y_va = torch.tensor(y_valid.values, dtype=f32).view(-1, 1)
loader = DataLoader(TensorDataset(X_tr, y_tr),
                    batch_size=16, shuffle=True)
model = nn.Sequential(
    nn.Linear(X_tr.shape[1], 128), nn.ReLU(), nn.Dropout(0.2),
    nn.Linear(128, 64), nn.ReLU(),
    nn.Linear(64, 1))                    # 회귀 → 출력 1개
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
⟦history⟧ = {'loss': [], 'val_loss': []}
for epoch in range(30):
    model.train(); total = 0
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward(); optimizer.step()
        total += loss.item() * len(xb)
    model.eval()
    with torch.no_grad():
        val = loss_fn(model(X_va), y_va).item()
    history['loss'].append(total / len(X_tr))
    history['val_loss'].append(val)
Q14
plt.plot(history['loss'])
plt.plot(history['val_loss'])
plt.title('Model Loss')
plt.xlabel('Epochs')
plt.ylabel('Loss')
plt.legend(['loss', 'val_loss'])
plt.show()
학습 루프 5줄이 핵심zero_grad() → 예측 → loss 계산 → backward() → step(). 이 순서는 회귀·분류 모두 똑같아요. 05 덱에서 한 줄씩 풀어 봐요.
dtype과 shape입력은 float32, 회귀 타깃은 (N, 1) 모양이에요. .view(-1, 1)을 빼면 MSELoss가 경고를 내고 학습이 엉뚱해져요.

잠깐 확인 클릭해서 정답 보기

문제에서 "결측치를 제거한 결과를 df_na에 저장하라"고 했어요. 다음 코드는 몇 점일까요?
df_temp.dropna(inplace=True)
0점일 가능성이 높아요. df_na라는 변수가 만들어지지 않았어요. df_na = df_temp.dropna()처럼 지정된 변수에 저장해야 해요.
회귀 문제의 마지막 층과 손실로 맞는 것은?
nn.Linear(64, 1) + nn.MSELoss() / nn.Linear(64, 1) + nn.Sigmoid() + nn.BCELoss()
앞쪽 Linear(64, 1) + MSELoss예요. 회귀는 값의 범위를 제한하면 안 되니까 마지막에 활성화 함수를 붙이지 않아요. sigmoid는 0~1 확률을 내는 이진분류용이에요.
시험 중 train_test_split 인자가 기억나지 않아요. 허용되는 방법은?
① Jupyter에서 Shift+Tab으로 도움말 보기 ② train_test_split? 실행하기 ③ scikit-learn 공식 문서에서 검색하기. 블로그나 ChatGPT는 부정행위예요.
