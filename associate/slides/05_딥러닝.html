PART 2

모델 쌓기

뉴런 하나가 하는 일, 층을 쌓는 법, 그리고 마지막 층(출력층)과 손실함수를 문제 유형에 맞추는 법을 봅니다.

출력층 + 손실 짝꿍이 핵심!

뉴런 하나 = 가중합 + 활성화

출력 = relu(w₁·tenure + w₂·요금 + w₃·계약 + b)

비유: 심사위원 한 명이 여러 항목 점수에 자기만의 가중치(w)를 곱해 더하고, 기준(b)을 넘으면 손을 드는 것과 같아요.

  • w, b는 학습으로 자동으로 정해져요. 우리가 정하는 건 뉴런 수와 층 수예요.
  • nn.Linear(33, 64) = 이런 뉴런 64개가 입력 33개와 모두 연결된 층이에요.
  • 활성화 함수가 없으면 층을 아무리 쌓아도 직선(선형) 모델이에요.
PyTorch는 활성화도 층이에요가중합은 nn.Linear, 활성화는 nn.ReLU()로 따로 넣어요.

층을 쌓으면 신경망이에요

입력 수

첫 nn.Linear의 입력 수 = 특성 수 = X_train.shape[1]. 그다음부터는 앞 층 출력 수 = 다음 층 입력 수예요.

은닉층

뉴런 수와 층 수는 문제가 정해줘요. 보통 128 → 64 → 32처럼 점점 줄여요. 활성화는 거의 항상 nn.ReLU()예요.

출력층

문제 유형이 결정해요. 회귀·이진분류는 1개, 다중분류는 클래스 수만큼이에요. sigmoid·softmax는 넣지 않아요.

특성이 20개인 데이터로 "64 → 32 → 출력" 이진분류 모델을 만들 때, 첫 층과 마지막 층은?
nn.Linear(20, 64)로 시작해 nn.Linear(32, 1)로 끝나요. 이진분류 출력은 로짓 1개이고, sigmoid는 넣지 않아요.
3개 클래스 분류 모델 끝에 nn.Softmax(dim=1)을 넣고 nn.CrossEntropyLoss()로 학습했어요. 뭐가 문제일까요?
softmax가 두 번 적용돼요. CrossEntropyLoss 안에 이미 softmax가 있으니, 모델은 nn.Linear(…, 3)에서 끝내야 해요.
다중분류 정답을 torch.tensor(y, dtype=torch.float32).reshape(-1, 1)로 만들었어요. 어떻게 고쳐야 할까요?
torch.tensor(y, dtype=torch.long)으로 바꿔요. dtype은 long, 모양은 (N,) 그대로예요. reshape하면 안 돼요.
nn.Linear(64, 32) 다음에 nn.Linear(16, 1)을 쌓았어요. 어떤 에러가 날까요?
mat1 and mat2 shapes cannot be multiplied예요. 앞 층 출력 수(32)와 다음 층 입력 수(16)가 같아야 해요.
PART 3

학습시키기

손실함수와 옵티마이저를 정하고, 학습 루프 5줄을 돌리면서 history를 기록하고, 검증 손실이 더 안 좋아지면 멈춥니다.

zero_grad → backward → step

손실함수 = 채점 기준, 옵티마이저 = 공부법

산에서 눈을 가리고 가장 낮은 곳을 찾는다고 생각하세요. lr은 한 걸음의 크기예요. 너무 크면 골짜기를 건너뛰고, 너무 작으면 해가 져요. Adam은 걸음 크기를 알아서 조절해서 기본값으로 가장 무난해요.

문제에 적힌 값 그대로"Adam, 학습률 0.001"이라고 나오면 torch.optim.Adam(model.parameters(), lr=0.001)로 옮겨요.
모델을 새로 만들면 옵티마이저도 새로옵티마이저는 만들 때의 model 파라미터를 기억해요. model을 다시 만들었다면 optimizer도 다시 만들어야 해요.

학습 루프 5줄 한 epoch 학습 함수

In [9]:
def train_one_epoch(model, loader, loss_fn, optimizer):
    model.train()                  # 학습 모드
    total = 0.0
    for xb, yb in loader:
        optimizer.⟦zero_grad⟧()      # ①
        out = model(xb)            # ②
        loss = loss_fn(out, yb)    # ③
        loss.⟦backward⟧()            # ④
        optimizer.⟦step⟧()           # ⑤
        total += loss.item() * len(xb)
    return total / len(loader.dataset)
  1. ①
    optimizer.zero_grad()지난번 채점 흔적(기울기) 지우기. 안 지우면 계속 쌓여요.
  2. ②
    out = model(xb)문제 풀기 (순전파)
  3. ③
    loss = loss_fn(out, yb)채점하기. 순서는 (예측, 정답)
  4. ④
    loss.backward()어디서 틀렸는지 거꾸로 추적 (역전파)
  5. ⑤
    optimizer.step()공부법 고치기 (가중치 업데이트)

확인 문제 ② 학습 · 예측

학습 루프에서 optimizer.zero_grad()를 빼먹으면 어떻게 될까요?
기울기가 배치마다 계속 더해져요. 가중치가 엉뚱하게 크게 바뀌어서 손실이 잘 줄지 않아요. 매 배치 시작에 꼭 지워요.
같은 검증 데이터로 두 번 예측했더니 결과가 매번 달라요. 무엇을 빠뜨렸을까요?
model.eval()이요. 학습 모드에서는 Dropout이 랜덤으로 뉴런을 꺼서 실행할 때마다 결과가 달라져요.
이진분류 로짓 0.9957은 1로 예측될까요, 0으로 예측될까요?
1이에요. sigmoid(0.9957) ≈ 0.73 > 0.5예요. 로짓이 0보다 크면 확률이 0.5보다 커요.
history['val_loss']가 15번째까지 내려가다가 그 뒤로 올라가요. 무슨 뜻이고 어떻게 해야 할까요?
과적합이에요. 조기 종료로 15번째의 state_dict를 저장해 두었다가 load_state_dict로 되돌려요.
loss.item() 대신 loss를 그대로 history에 append하면 무엇이 문제일까요?
숫자가 아니라 계산 그래프가 달린 텐서가 쌓여요. 메모리를 계속 차지하고 그래프 그리기도 번거로워요. .item()으로 float만 꺼내요.

05 정리 이것만은 손에 익히기

import torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

Xtr = torch.tensor(X_train, dtype=torch.float32)
ytr = torch.tensor(y_train.to_numpy(), dtype=torch.float32).reshape(-1, 1)
loader = DataLoader(TensorDataset(Xtr, ytr), batch_size=32, shuffle=True)

torch.manual_seed(42)
model = nn.Sequential(nn.Linear(Xtr.shape[1], 64), nn.ReLU(),
                      nn.Linear(64, 1))
loss_fn = nn.BCEWithLogitsLoss()      # 회귀 MSELoss · 다중 CrossEntropyLoss
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

history = {'loss': [], 'val_loss': []}
for epoch in range(30):
    model.train()
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward(); optimizer.step()
    history['loss'].append(loss.item())   # 마지막 배치 손실
    model.eval()
    with torch.no_grad():
        history['val_loss'].append(loss_fn(model(Xte), yte).item())

with torch.no_grad():
    pred = (torch.sigmoid(model(Xte)) > 0.5).int().numpy().flatten()
  1. X는 float32, y는 회귀·이진이면 (N, 1), 다중이면 long (N,)
  2. 출력층에 sigmoid·softmax를 넣지 않아요. 손실함수 안에 있어요.
  3. 루프 5줄: zero_grad → model → loss → backward → step
  4. history 딕셔너리에 .item()으로 기록해요.
  5. 예측은 eval() + no_grad(), 그다음 sigmoid / argmax예요.
