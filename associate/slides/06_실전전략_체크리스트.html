문서 한 페이지 30초 만에 읽기

DataFrame.dropna(*, axis=0, how=<no_default>, thresh=<no_default>,
                 subset=None, inplace=False, ignore_index=False)

Remove missing values.

Parameters
  axis : {0 or 'index', 1 or 'columns'}, default 0
  how : {'any', 'all'}, default 'any'
  subset : column label or sequence of labels, optional
  inplace : bool, default False

Returns
  DataFrame or None
      DataFrame with NA entries dropped from it or None if inplace=True.

Examples
  >>> df.dropna(subset=['name', 'toy'])

pandas 2.2 DataFrame.dropna 문서 구조를 요약했어요.

① 첫 줄 · Signature

어떤 인자가 있고 기본값이 뭔지 한눈에 봐요. axis=0이 기본이라 행 삭제예요.

② Returns

무엇을 돌려주는지 봐요. "None if inplace=True" → inplace를 쓰면 반환값이 없으니 변수에 저장하면 안 돼요.
